# v4.5.1 · Mind+ 兼容版

本版本让 StarBridge 支持 Python 3.8 及以上版本，可在 Mind+ 自带的 Windows 64 位 Python 3.8.5 环境安装和运行。安装包仍叫 `starbridge-hardware`，Python 导入名仍为 `starbridge`。

## 更新内容

- 将最低 Python 版本从 3.10 调整为 3.8。
- 替换旧版 Python 不提供的 `StrEnum`，保留板型枚举的字符串与 JSON 行为。
- 移除 Python 3.8 不支持的 dataclass `slots` 参数，保留数据对象的不可变行为。
- 保留 StarCore V2 / StarDust 的固件、Windows 离线烧录器与现有 Python API。
- 增加 Mind+ 安装说明，以及 Windows Python 3.8–3.13 的 wheel 安装与 SDK 测试流程。

## 验证

已在 Mind+ 实际使用的 Python 3.8.5 / pip 22.0.4 中安装 wheel，45 项测试通过。测试覆盖协议、GPIO、传感器、OLED、NFC、网络模块、模拟烧录流程和离线资源完整性；本次未进行实体开发板测试。

## 安装

在 Mind+ 的 Python 库管理中安装 `starbridge-hardware==4.5.1`。也可以使用 Mind+ 自己的 Python 解释器执行：

```powershell
python -m pip install --upgrade "starbridge-hardware==4.5.1" -i https://pypi.org/simple/
```

请确认这里的 `python` 指向 Mind+ 的解释器。镜像源需要等待同步；本地 wheel 安装不需要等待镜像。

详细路径示例见 [Mind+ 安装与使用](../mindplus.md)。

## 旧版本

PyPI 上的 4.5.0 保留，不覆盖或删除。Python 3.10 及以上环境仍可以指定安装 `starbridge-hardware==4.5.0`；Mind+ 的 Python 3.8 环境应使用 4.5.1。
