# 第四版路线图

## M0：基线与规则

- [x] 提取第三版可维护源码
- [x] 提取后续扩展 SDK 作为迁移参考
- [x] 复现第三版 ESP32 固件编译
- [x] 记录高风险问题与版本策略
- [ ] 确认第四版首发硬件型号和引脚映射

## M1：协议 V2

- [x] 定义帧格式、字节序和最大载荷
- [x] 定义请求序号、响应和异步事件类型
- [x] 定义 CRC、超时与错误码
- [x] 定义版本/板型/能力握手
- [x] 建立跨语言协议黄金测试向量

完成标准：同一组测试向量在 C++ 与 Python 中编码结果完全一致，损坏帧会被稳定拒绝并恢复同步。

## M2：ESP32 核心固件

- [x] 建立 PlatformIO/Arduino CLI 双构建入口
- [x] 实现非阻塞串口 transport 与帧解析器
- [x] 实现数字 IO、ADC 与 DAC
- [x] 重写 LEDC channel 资源管理
- [x] 加入运行状态清理
- [x] 加入固件信息与能力查询
- [ ] 增加硬件看门狗策略

完成标准：连续运行压力测试无丢包；多 PWM 组合测试通过；重复连接和复位后状态一致。

## M3：Python SDK 4.0

- [x] 建立 `pyproject.toml` 和 `src/` 布局
- [x] 实现串口连接与确定性关闭
- [x] 实现请求序号对应的同步 API
- [x] 建立明确的异常类型
- [x] 建立模拟串口测试
- [x] 实现按板型发现串口、固件检查、首次自动烧录和烧录后重连
- [ ] 实现运行中断线重连和第三版兼容层
- [ ] 完成 Python 3.10–3.13 CI 矩阵

完成标准：模拟串口测试不依赖真机；所有后台错误可由调用方观察；安装包不强制依赖 OpenCV/Pillow。

## M4：首发模块

- [x] WS2812（Adafruit NeoPixel）
- [x] DHT11（DFRobot_DHT11）
- [x] 超声波测距
- [x] DFR0534 软件串口 MP3
- [ ] 按钮、光照、气体、电位器
- [ ] UART1/UART2
- [x] SSD1306 OLED 与 GB2312 中文显示
- [x] 星核板 V2 固件自动烧录

DFR0534 使用独立的 9600 baud 软件串口；通用软串口透传暂不进入首发范围。
