星核板 V2

ESP32 开发板，使用 BoardType.STARCORE_V2 和 Pin 引脚枚举。

3.3V 逻辑Wi-FiESP-NOWADC / DACI²C

安装与连接

python -m pip install --upgrade starbridge-hardware
from starbridge import Board, BoardType

with Board.begin(BoardType.STARCORE_V2) as board:
    info = board.info()
    print("固件版本：", f"{info.firmware_major}.{info.firmware_minor}.{info.firmware_patch}")
    print("功能位：", hex(info.capabilities))
只有一块匹配设备时会自动选择串口；连接多块开发板时可写成 Board.begin(BoardType.STARCORE_V2, port="COM4")。

引脚说明

普通接口P0～P20，按板上丝印选择
仅输入P2、P3、P4、P10
DACP8 / GPIO26，P9 / GPIO25
I²CSDA=P20，SCL=P19
板载灯珠Pin.ONBOARD_PIXELS
板载蜂鸣器Pin.BUZZER
星核板是 3.3V 逻辑。5V 输出信号接入 ESP32 前必须使用分压或电平转换。

数字输入输出

P0 控制 LED，板载按键 A 作为上拉输入。按键按下时读取为低电平。

import time
from starbridge import Board, BoardType, Pin, PinMode

with Board.begin(BoardType.STARCORE_V2) as board:
    board.pin_mode(Pin.P0, PinMode.OUTPUT)
    board.pin_mode(Pin.BUTTON_A, PinMode.INPUT_PULLUP)
    while True:
        pressed = not board.digital_read(Pin.BUTTON_A)
        board.digital_write(Pin.P0, pressed)
        print("按下" if pressed else "松开")
        time.sleep(0.05)

ADC 与 DAC

analog_read() 可返回 ADC 原始值或毫伏值；P8、P9 支持 0～255 的 8 位 DAC 输出。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    print("P0 原始值：", board.analog_read(Pin.P0))
    print("P0 电压：", board.analog_read(Pin.P0, millivolts=True), "mV")
    print("板载光线：", board.analog_read(Pin.LIGHT))
    for value in range(0, 256, 8):
        board.analog_write(Pin.P8, value)
        time.sleep(0.03)
    board.analog_write(Pin.P8, 0)

PWM 与蜂鸣器

先设置频率和分辨率，再写入占空比。8 位分辨率下的 128 约等于 50%。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    board.pwm_configure(Pin.BUZZER, frequency=1000, resolution=8)
    board.pwm_write(Pin.BUZZER, 128)
    time.sleep(1)
    board.pwm_stop(Pin.BUZZER)

DHT11 温湿度

DATAP1
VCC3.3V
GNDGND
DATA 必须连接可双向工作的引脚。裸传感器通常需要在 DATA 与 VCC 之间接 4.7kΩ～10kΩ 上拉电阻。
import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    sensor = board.dht11(Pin.P1)
    while True:
        data = sensor.read()
        print(f"温度 {data.temperature_c:.1f} °C")
        print(f"湿度 {data.humidity_percent:.1f} %")
        time.sleep(2)

WS2812 / NeoPixel

板载三颗灯珠使用 Pin.ONBOARD_PIXELS，每颗灯珠分别设置 RGB 后调用 show()。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    pixels = board.neopixel(Pin.ONBOARD_PIXELS, 3, brightness=64)
    for index, color in enumerate([(255, 0, 0), (0, 255, 0), (0, 0, 255)]):
        pixels.set_pixel(index, *color)
    pixels.show()
    time.sleep(2)
    pixels.clear()

超声波测距

TRIGP6
ECHOP7，经分压
GND与开发板共地
HC-SR04 的 ECHO 通常输出 5V，必须分压到约 3.3V 后再接入星核板。
import time
from starbridge import Board, BoardType, Pin
from starbridge.errors import BoardCommandError

with Board.begin(BoardType.STARCORE_V2) as board:
    sonar = board.ultrasonic(Pin.P6, Pin.P7)
    while True:
        try:
            print(f"距离 {sonar.read_cm():.1f} cm")
        except BoardCommandError:
            print("没有收到回波")
        time.sleep(0.5)

PN532 NFC（I²C）

SDAP20 / GPIO23
SCLP19 / GPIO22
地址0x24
模式I²C
先把模块拨码或焊盘切换到 I²C 模式。写卡时不要移动标签，SDK 会保护扇区尾块、锁定位和配置页。
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    nfc = board.pn532(reset_pin=Pin.P0).begin()
    print("固件：", nfc.firmware_info())
    uid = nfc.scan(timeout=0.25)
    if uid is not None:
        print("UID：", uid.hex("-").upper())
        print("第 4 页：", nfc.read_page(4))
        nfc.write_page(4, b"NFC!")

通用软串口

第一个引脚是 RX，第二个引脚是 TX。适合连接使用 UART 的传感器、执行器和 AT 指令模块。

from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    uart = board.software_serial(Pin.P6, Pin.P7, 9600)
    uart.write(b"AT\r\n")
    print(uart.read(timeout=1.0))
    uart.close()

Wi-Fi、ESP-NOW 与网络时间

ESP32 使用 2.4 GHz Wi-Fi。Wi-Fi 已连接时，ESP-NOW 应使用接入点所在的同一信道。
from starbridge import Board, BoardType

with Board.begin(BoardType.STARCORE_V2) as board:
    wifi = board.wifi()
    print(wifi.connect("你的 Wi-Fi", "密码"))
    print(board.network_time().synchronize(utc_offset=8 * 3600))
    radio = board.espnow()
    radio.add_peer("AA:BB:CC:DD:EE:FF")
    radio.send("AA:BB:CC:DD:EE:FF", b"hello")
    print(radio.receive())

星尘板

ATmega328P、16 MHz、5V 逻辑，使用 BoardType.STARDUST 和 StardustPin 引脚枚举。

CH340 USB 串口5V 逻辑ADCPWMI²C

安装与连接

python -m pip install --upgrade starbridge-hardware
from starbridge import Board, BoardType

with Board.begin(BoardType.STARDUST) as board:
    info = board.info()
    print("固件版本：", f"{info.firmware_major}.{info.firmware_minor}.{info.firmware_patch}")
    print("功能位：", hex(info.capabilities))
D0/RX 和 D1/TX 用于电脑与开发板之间的协议通信，不作为普通 GPIO 使用。连接多块设备时可以指定 port="COM5"。

引脚说明

数字 I/OD2、D3、D5、D6、D9、D10
数字 I/O + ADCA0、A1、A2、A3
PWMD3、D5、D6、D9、D10
专用 I²CSDA=A4，SCL=A5
协议串口D0 / D1，不开放
逻辑与供电5V
A4、A5 专用于 I²C 外设，不作为通用 GPIO。星尘板没有 DAC、Wi-Fi 和 ESP-NOW。

数字输入输出

D2 输出电平，D3 接按钮并使用内部上拉。按钮另一端接 GND。

import time
from starbridge import Board, BoardType, PinMode, StardustPin

with Board.begin(BoardType.STARDUST) as board:
    board.pin_mode(StardustPin.D2, PinMode.OUTPUT)
    board.pin_mode(StardustPin.D3, PinMode.INPUT_PULLUP)
    while True:
        pressed = not board.digital_read(StardustPin.D3)
        board.digital_write(StardustPin.D2, pressed)
        print("按下" if pressed else "松开")
        time.sleep(0.05)

ADC 与 PWM

A0～A3 可读取 10 位 ADC；PWM 是 8 位固定频率输出。D5、D6 为 980 Hz，D3、D9、D10 为 490 Hz。

import time
from starbridge import Board, BoardType, StardustPin

with Board.begin(BoardType.STARDUST) as board:
    print("A0 原始值：", board.analog_read(StardustPin.A0))
    print("A0 电压：", board.analog_read(StardustPin.A0, millivolts=True), "mV")
    board.pwm_configure(StardustPin.D9, frequency=490, resolution=8)
    for duty in range(0, 256, 8):
        board.pwm_write(StardustPin.D9, duty)
        time.sleep(0.03)
    board.pwm_stop(StardustPin.D9)

MP3 与通用软串口使用相同的 AVR 软件串口资源。程序中应只启用其中一种，后初始化的功能会关闭前一路。

通用软串口

第一个引脚是 RX，第二个引脚是 TX；支持 300～115200 baud，单次读写最多 96 字节。

from starbridge import Board, BoardType, StardustPin

with Board.begin(BoardType.STARDUST) as board:
    uart = board.software_serial(StardustPin.D5, StardustPin.D6, 9600)
    uart.write(b"AT\r\n")
    print(uart.read(maximum=32, timeout=1.0))
    uart.close()

综合示例：环境显示器

DHT11 使用 D2，超声波使用 D5/D6，OLED 使用专用 A4/A5。没有回波时程序仍会继续刷新。

import time
from starbridge import Board, BoardType, StardustPin
from starbridge.errors import BoardCommandError

with Board.begin(BoardType.STARDUST) as board:
    climate = board.dht11(StardustPin.D2)
    sonar = board.ultrasonic(StardustPin.D5, StardustPin.D6)
    oled = board.oled().begin(0x3C)
    while True:
        reading = climate.read()
        try:
            distance = f"距离 {sonar.read_cm():.1f} cm"
        except BoardCommandError:
            distance = "距离 无回波"
        oled.clear()
        oled.text(0, 12, f"温度 {reading.temperature_c:.1f} C")
        oled.text(0, 30, f"湿度 {reading.humidity_percent:.1f} %")
        oled.text(0, 48, distance)
        oled.show()
        time.sleep(2)

异常处理

找不到开发板、固件安装失败或元器件没有响应时，可以分别捕获对应异常。

from starbridge import Board, BoardType, StardustPin
from starbridge.errors import BoardCommandError, BoardNotFoundError, FirmwareInstallError

try:
    with Board.begin(BoardType.STARDUST) as board:
        print(board.dht11(StardustPin.D2).read())
except BoardNotFoundError as error:
    print("未找到星尘板：", error)
except FirmwareInstallError as error:
    print("固件安装失败：", error)
except BoardCommandError as error:
    print("元器件通信失败：", error)
