安装与连接

Windows wheel 内置固件、esptool 和串口运行库，不需要 Arduino IDE 或 Arduino CLI。

python -m pip install https://github.com/HAOTIANGUO22/StarBridge/releases/download/v4.4.0/starbridge-4.4.0-py3-none-any.whl

自动识别开发板

from starbridge import Board, BoardType

with Board.begin(BoardType.STARCORE_V2) as board:
    print(board.info())
4.4.0 同时识别 CP210x 与 CH9102。存在多个相同设备时，可传入 port="COM4"。

数字输入输出

用 P0 输出高低电平，并读取板载 A 按钮。

import time
from starbridge import Board, BoardType, Pin, PinMode

with Board.begin(BoardType.STARCORE_V2) as board:
    board.pin_mode(Pin.P0, PinMode.OUTPUT)
    board.pin_mode(Pin.BUTTON_A, PinMode.INPUT_PULLUP)

    while True:
        pressed = not board.digital_read(Pin.BUTTON_A)
        board.digital_write(Pin.P0, pressed)
        print("按下" if pressed else "松开")
        time.sleep(0.05)

模拟量 / ADC

P0 支持原始 ADC 数值和毫伏值读取。板载光线传感器可使用 Pin.LIGHT。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    while True:
        raw = board.analog_read(Pin.P0)
        millivolts = board.analog_read(Pin.P0, millivolts=True)
        light = board.analog_read(Pin.LIGHT)
        print(f"P0={raw}, {millivolts} mV, 光线={light}")
        time.sleep(0.2)

模拟输出 / DAC

P8/GPIO26 和 P9/GPIO25 支持 8 位 DAC，取值范围为 0–255。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    for value in range(0, 256, 8):
        board.analog_write(Pin.P8, value)
        time.sleep(0.03)
    board.analog_write(Pin.P8, 0)

PWM 与板载蜂鸣器

以下示例在板载蜂鸣器上输出 1 kHz 方波。占空比 128 对应 8 位分辨率下约 50%。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    board.pwm_configure(Pin.BUZZER, frequency=1000, resolution=8)
    board.pwm_write(Pin.BUZZER, 128)
    time.sleep(1)
    board.pwm_stop(Pin.BUZZER)

DHT11 温湿度

DATAP1
VCC3.3V
GNDGND
DHT11 需要双向引脚。不要使用仅输入的 P2、P3、P4、P10。裸传感器通常还需要 4.7kΩ–10kΩ 上拉电阻。
import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    sensor = board.dht11(Pin.P1)
    while True:
        data = sensor.read()
        print(f"温度 {data.temperature_c:.1f} °C")
        print(f"湿度 {data.humidity_percent:.1f} %")
        time.sleep(2)

WS2812 / NeoPixel

板载共有 3 颗 WS2812B，数据脚可用 Pin.ONBOARD_PIXELS。

import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    pixels = board.neopixel(Pin.ONBOARD_PIXELS, 3, brightness=64)
    colors = [(255, 0, 0), (0, 255, 0), (0, 0, 255)]

    for index, color in enumerate(colors):
        pixels.set_pixel(index, *color)
    pixels.show()
    time.sleep(2)
    pixels.clear()

超声波测距

TRIGP6
ECHOP7，经分压
VCC按模块要求
GND共地
HC-SR04 的 ECHO 通常为 5V，接入 ESP32 前必须分压至约 3.3V。物体紧贴探头会进入盲区，应捕获无回波异常。
import time
from starbridge import Board, BoardType, Pin
from starbridge.errors import BoardCommandError

with Board.begin(BoardType.STARCORE_V2) as board:
    sonar = board.ultrasonic(Pin.P6, Pin.P7)
    while True:
        try:
            print(f"距离 {sonar.read_cm():.1f} cm")
        except BoardCommandError as error:
            print(error)  # 过近、超出量程或没有回波时继续运行
        time.sleep(0.5)

DFR0534 MP3 模块

模块 T开发板 RX / P13
模块 R开发板 TX / P14
BUSYP15，可省略
波特率9600
import time
from starbridge import Board, BoardType, Pin

with Board.begin(BoardType.STARCORE_V2) as board:
    mp3 = board.mp3(Pin.P13, Pin.P14, Pin.P15)
    mp3.set_volume(20)
    mp3.play_track(1)
    time.sleep(5)
    mp3.pause()
    time.sleep(1)
    mp3.play()
    print("模块状态:", mp3.status())
    print("正在播放:", mp3.is_busy())

综合示例：环境仪表

DHT11、超声波和 OLED 同时工作；无回波时屏幕继续刷新，不会退出程序。

import time
from starbridge import Board, BoardType, Pin
from starbridge.errors import BoardCommandError

with Board.begin(BoardType.STARCORE_V2) as board:
    climate = board.dht11(Pin.P1)
    sonar = board.ultrasonic(Pin.P6, Pin.P7)
    oled = board.oled().begin()

    while True:
        reading = climate.read()
        try:
            distance_text = f"距离: {sonar.read_cm():.1f} cm"
        except BoardCommandError:
            distance_text = "距离: 过近或无回波"

        oled.clear()
        oled.text(0, 8, f"温度: {reading.temperature_c:.1f} C")
        oled.text(0, 26, f"湿度: {reading.humidity_percent:.1f} %")
        oled.text(0, 44, distance_text)
        oled.show()
        time.sleep(1)

异常处理

4.4.0 的异常会直接说明功能、可能原因和处理建议，同时保留命令号与状态码供开发者排查。

from starbridge import Board, BoardType, Pin
from starbridge.errors import (
    BoardCommandError,
    BoardNotFoundError,
    FirmwareInstallError,
)

try:
    with Board.begin(BoardType.STARCORE_V2) as board:
        print(board.dht11(Pin.P1).read())
except BoardNotFoundError as error:
    print("未找到开发板：", error)
except FirmwareInstallError as error:
    print("固件安装失败：", error)
except BoardCommandError as error:
    print(error)
    print("命令号：", hex(error.command))
    print("状态码：", error.status)
